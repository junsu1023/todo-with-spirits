윈도우 앱 디자인 시안 v4

Figma Mobile_GUI의 색과 구성을 바탕으로, 둥글고 부드러운 톤과 나눔스퀘어라운드 글꼴로 만든 1280×800 창 시안이에요.
각 화면은 실제로 눌러 볼 수 있고, 사이드바로 서로 이동할 수 있어요.

모든 화면 공통
  • 알림(벨 아이콘): 오른쪽 알림 패널 — 종류별 보기(전체·시스템·이벤트·정령의숲), 읽음·지우기, 누르면 관련 화면으로 이동
  • 애니메이션: 화면 진입 시 순서대로 떠오르기, 화면 전환 페이드, 완료 체크 튕김, 새 항목 등장, 패널 슬라이드, 토스트, 버튼 눌림
  • Windows "애니메이션 효과 끄기"(동작 줄이기) 설정을 켜면 움직임이 멈춰요
  • 다크 모드: 창 오른쪽 위 달 아이콘, 또는 설정 › 디스플레이 (라이트·다크·시스템, 글자 대비 높이기). 색 대비 분석은 CONTRAST.md
  • 왼쪽 패널: 창 왼쪽 위 ▯ 아이콘(Ctrl+B)으로 고정/숨김, 숨긴 상태에서는 ≡ 아이콘 또는 창 왼쪽 끝에 마우스를 대면 잠깐 열림
  • 창 크기: 위쪽 막대에서 1440×900 · 1280×800(기본) · 1100×720 · 960×640(최소) 선택, 창 오른쪽 아래 모서리를 끌어 직접 조절. 1100 미만이면 왼쪽 패널이 자동으로 숨고 홈 상세 패널은 겹쳐서 열림
  • 캘린더 월간·연간: 칸에는 날짜와 일정 개수만 두고 내용은 목록에서 읽음. 연간은 날짜를 누르면 그 달로 이동
  • 캘린더 주간 보기: 위는 한 주 띠(날짜·일정 개수), 아래는 고른 날 하루의 큰 목록. 일정을 누르면 오른쪽에서 상세가 나옴
  • 공용 스타일 styles/app.css, 공용 스크립트 scripts/app.js
