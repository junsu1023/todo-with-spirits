## 2. 공통 패턴

1. **주간은 넓게 쓴다.** 7일을 한 화면에 둘 때는 상세 패널을 접거나(캘린더형), 칸 수를 줄이고 가로로 넘긴다(Todoist 보드·모바일 3일).
2. **세 가지 모양.** 날짜별 칸(보드), 시간 격자(캘린더), 날짜별 목록(Things·To Do·Any.do 7일). TODO 앱은 일정에 길이가 없어서 보드나 목록이 더 흔하다.
3. **종일과 시간 있는 일을 나눈다.** 종일 일은 위에 모으고(Notion은 접기까지), 시간 있는 일은 시간 순서로.
4. **하루 진행을 보여 준다.** Sunsama는 칸마다 진행 막대.
5. **오늘은 강조, 지난 날은 한 단계 흐리게.**
6. **바로 추가.** 칸 아래 "+" 또는 빈 곳 두 번 누르기.

## 3. 거쳐 온 시안 (채택하지 않음)

7일 칸 안에서 모양만 바꾼 시안 다섯 가지(A 점 목록, B 체크리스트, C 시간대 줄, D 컬러 블록, E 날짜별 목록)를 만들어 비교했으나 모두 읽기 어려웠다. 원인은 같았다. "한 주를 훑어보기"와 "내용을 읽기"를 한 칸에 넣으면 글자가 11~13px로 줄고 제목이 꺾인다. 시안 코드와 비교 페이지는 지웠다.

## 4. 최종: 주간 띠 + 날짜별로 이어지는 큰 목록

처음 보는 사람이 몇 초 안에 "지금 어디를 보나 → 뭐가 중요한가 → 뭘 누르나"를 알 수 있게 하는 것을 기준으로 삼았다.

| 원칙 | 적용 |
|---|---|
| 한 화면에 주인공은 하나 | 띠는 "어느 날이 바쁜가"(날짜·일정 개수)만, 목록은 "무슨 일인가"만 |
| 본문 15px 이상, 한 줄에 한 일정 | 홈 화면과 같은 카드를 그대로 사용 |
| 색에 뜻을 맡기지 않는다 | "오늘", "5개", "모두 완료", "5개 중 1개 완료"처럼 글자로. 중요는 ★, 완료는 체크와 취소선 |
| 사람이 쓰는 말 | 요일은 한글, 날짜 머리는 "13일 화요일" |
| 위계는 세 단계 | 날짜 머리(17px 굵게) → 제목(15px) → 시간·반복(작고 흐리게) |
| 누를 수 있는 건 눌러 보이게 | 날짜마다 항상 보이는 "+ 일정 추가", 카드의 동그라미로 완료 |

동작:
- 주간 보기를 열면 오늘이 맨 위. 지난 날은 위로 스크롤.
- 띠에서 날짜를 누르면 그 날 머리로 이동. ← → 하루, PageUp/Down 한 주.
- 일정이 없는 날도 "일정 없음" 한 줄로 남긴다.
- 오른쪽 패널은 접혀 있다가, 일정을 누르면 상세, "+ 일정 추가"를 누르면 추가 폼이 밀려 나온다. Esc로 닫는다. 월간·연간은 이전과 같다.
- 완료를 눌러도 보던 스크롤 위치가 유지된다.

확인(2026-11-25): 라이트·다크 × 1280·960 창에서 글자 대비 통과, 위 동작 전부 통과, 스크립트 오류 없음. 실제로 처음 보는 사람에게 보여 주는 확인은 하지 않았다.

## 5. 고친 것 (2026-11-25, 이어서)

- 아래 목록은 **고른 날 하루만** 보여 준다. 한 주가 이어지던 목록은 스크롤해도 띠의 선택 표시가 따라오지 않아 헷갈렸다. 다른 날은 띠를 누르거나 ← →로 본다.
- 주간에서는 오른쪽 패널이 상세·추가일 때만 열리고, 뒤로·Esc·확인을 누르면 바로 닫힌다(그날 목록은 가운데에 이미 있으므로).
- 시간 표기를 홈·캘린더 모두 "오후 2:30" 형식으로 바꿨다. 일정 폼의 시간 선택(19 : 00 휠)은 24시간 그대로다.
- 일정 추가를 열 때 제목 칸으로 커서가 가면서 화면이 옆으로 밀리던 문제를 고쳤다(홈·캘린더).

## 6. 월간·연간도 같은 원칙으로 (2026-11-25)

**월간** — 칸은 "어느 날이 바쁜가"만, 내용은 오른쪽 목록에서 읽는다.
- 칸 안의 11px 일정 제목 두 줄과 "+3", "중요 2" 꼬리표를 없애고, 날짜(16px)와 일정 개수("5개", "모두 완료", 끝내지 않은 중요가 있으면 ★)만 둔다. 주간 띠와 같은 표기다.
- 요일을 한글로, 오늘 칸에는 "오늘" 글자, 지난 날은 날짜를 한 단계 흐리게.
- 오른쪽 목록 머리말을 "10월 13일 화요일 · 오늘"과 "5개 중 1개 완료" 문장으로.

**연간** — 한 해를 훑고 달을 고르는 화면.
- 오른쪽 패널을 접어 12달을 넓게 쓰고, 날짜 숫자를 10px에서 12px로, 요일을 한글로.
- 날짜를 한 번 누르면 그 달의 그 날로 이동한다(예전에는 두 번 눌러야 했다). 달 이름을 눌러도 이동.
- 이번 달은 "이번 달" 꼬리표, 달마다 "일정 n개"를 문장으로. 색 뜻은 위 범례에 적는다.
- 1280×800 창에서는 12달이 스크롤 없이 한 화면에 들어오고, 960×640에서는 세로로 스크롤한다.

확인: 라이트·다크 × 1280·960에서 글자 대비 통과, 칸 안 글자 잘림 없음, 날짜 선택·두 번 눌러 추가·연간에서 달 이동·Ctrl+N·Esc 동작, 스크립트 오류 없음.

- (추가) 월간 칸에 아직 안 끝낸 첫 일정의 제목 한 줄(12px, 넘치면 …)을 남기고, 나머지는 "외 4개"로 적는다. 모두 끝낸 날은 "모두 완료"만 보인다. 1280 창에서 제목은 다섯 글자쯤 보인다.
