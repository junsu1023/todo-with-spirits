# 「정령의 하루」 아트 제작 목록과 GPT 요청 프롬프트

작성: 2026-09-18 · 기준: [정령의 하루 상세 기획 v4](ForestDailyExperiencePlanV4.md) · 성격: 제작 요청서, 구현 완료 판정 아님

## 1. 제작 범위 판단

**확인한 사실:** 현재 프로젝트에는 세로 숲 배경, 종이 패널·버튼·아이콘, 보상/터치 이펙트, 분홍 바람 정령의 기본 표정·포즈, 숲 장식, 책·가방·수첩·찻잔·방석·편지 등의 소품이 있다. [Art Kit 통합 기록](Concept01ArtKitIntegration.md)은 PNG Sprite 197개를 보고한다. 실제 UI는 기존 분홍 정령 4포즈를 사용한다.

**제작 판단:** P0 첫 입장 팝업의 카드·목록·보상 표시·하향 닫힘에는 신규 그림이 필수는 아니다. 하향 이동은 Unity UI 애니메이션 작업이다. P1의 `TODO → 정령의 생활`을 한눈에 알아보려면 정령 활동 포즈와 배치 가능한 생활 장소가 우선 필요하다. P2 전용 결과물과 P4 성체 외형은 사건 대본·성장 정책을 확정한 뒤 발주한다.

**비주얼 기준:** 기존 **분홍 바람 정령**을 유지한다. 첨부된 컨셉 보드의 새싹 캐릭터, 레벨·보석 UI는 이번 확정 기획의 제작 대상이 아니다.

### 복사해서 GPT 이미지 제작 대화에 보내는 프롬프트

아래 프롬프트와 함께 **참고 이미지 네 장을 실제로 첨부**한다. 다른 대화의 GPT는 이 저장소의 로컬 경로만으로 파일을 볼 수 없다.

1. `Assets/TodoSpirits/Art/Forest/wind-spirit-expressions.png` — 캐릭터의 최우선 기준
2. `Assets/TodoSpiritsArtKit/Sprites/Spirit/spirit_neutral.png` — 현재 게임에서 쓰는 분홍 정령의 단일 Sprite
3. `Assets/TodoSpiritsArtKit/Backgrounds/bg_forest_storybook_fallback.png` — 숲의 색·밀도·시점
4. `Assets/TodoSpirits/Art/Forest/forest-props-release.png` — 가구·소품의 선·질감·색 기준

```text
당신은 Unity 6 모바일 게임에 들어갈 실제 2D Sprite를 제작하는 아티스트입니다. 첨부한 네 이미지를 시각적 원본으로 사용해 주세요. 캐릭터 기준은 분홍 바람 정령 이미지입니다. 같은 캐릭터의 새 동작을 그리는 작업이며, 새싹 캐릭터나 다른 동물로 재해석하지 마세요.

화풍: 아늑한 2D 그림책 게임 일러스트. 단순하고 둥근 형태, 얇고 부드러운 윤곽선, 따뜻한 아이보리·세이지색·연한 분홍·연갈색, 절제된 구아슈/종이 질감과 부드러운 명암. 첨부된 정령의 구름형 몸, 분홍 테두리, 얼굴 비율, 꼬리, 팔의 위치와 채도를 일관되게 유지합니다. 배경과 가구는 기존 숲의 정면/약한 3/4 시점을 따릅니다. 사진, 3D 렌더, 진한 검정 윤곽, 복잡한 픽셀 패턴은 피합니다.

출력 규칙: 아래 10개 ID를 각각 독립된 512×512 PNG 이미지로 제작하세요. 한 장에 여러 항목을 모은 시트, 목업, 게임 화면, UI 카드, 글자, 숫자, 로고, 워터마크는 만들지 마세요. 각 PNG는 물체 외부와 네 모서리가 실제 알파 0인 투명 배경이어야 합니다. 흰색·검은색·체커보드 무늬를 투명 배경처럼 그리지 마세요. 전체 형태가 잘리지 않게 충분한 투명 여백을 두고, 같은 종류의 정령 포즈는 같은 크기와 위치로 정렬하세요. 정령은 바닥을 기준으로 같은 높이에 배치하고 몸 전체가 프레임 안에 들어가야 합니다. 가구는 정령을 덮지 않도록 독립 Sprite로 만듭니다.

제작 목록:
1. spirit_read_01 — 첨부 캐릭터가 작은 펼친 책을 보고 집중하는 모습.
2. spirit_read_02 — 01과 몸 크기·책 위치는 유지하고 시선을 살짝 들거나 페이지에 반응하는 모습. 두 장을 번갈아 표시해도 흔들리지 않아야 합니다.
3. spirit_move_01 — 숲길에서 오른쪽으로 둥실 떠서 움직이는 모습. 구름 몸과 꼬리를 유지하며 다리·신발을 추가하지 마세요.
4. spirit_move_02 — 03과 크기·방향은 같고 떠오른 높이와 꼬리의 움직임만 조금 다릅니다.
5. spirit_make_01 — 작은 생활 물건을 조심스럽게 손질하거나 만드는 모습.
6. spirit_make_02 — 05와 같은 물건을 마무리하고 만족스러운 표정을 짓는 모습. 루프로 연결돼도 형태가 튀지 않아야 합니다.
7. spirit_tea_01 — 기존 찻잔 소품과 함께 배치할 수 있도록 인사를 준비하며 찻잔 쪽을 바라보는 모습. 장면이나 테이블은 포함하지 마세요.
8. station_desk — 작은 둥근 나무 책상. 작업면과 캐릭터 배치 여백이 보이며, 책·수첩 Sprite를 나중에 따로 올릴 수 있어야 합니다.
9. station_workbench — 숲속의 낮은 공작대. 나무 재질, 간결한 형태, 작은 물건을 나중에 따로 올릴 여백.
10. station_tea_table — 낮고 둥근 나무 티테이블. 기존 찻잔·편지 Sprite를 따로 얹을 수 있는 여백.

먼저 spirit_read_01과 station_desk를 제작해 일관된 스타일·실제 투명도·배치 가능한 크기를 확인받으세요. 그다음 같은 스타일로 나머지를 한 항목씩 제작하세요. 각 결과의 ID와 실제 출력 크기, 투명 배경 여부를 함께 알려 주세요. 512×512 또는 진짜 투명 PNG를 출력할 수 없다면 그 사실을 숨기지 말고 실제 결과를 명시하세요. 이미 있는 숲 배경·기본 표정·UI·책장·공구함·찻잔·방석·가방·수첩은 다시 제작하지 마세요.
```

## 4. 사건·성장 확정 뒤의 후속 발주

**P2 사건 결과물:** 3개 입력 유형 × 3장면의 대본·선택 A/B가 확정되면, 각 선택의 `즉시/숲 화면/다음 방문`에서 실제로 보일 소품을 목록화한다. 기존 `forest-journey-props.png`의 수첩·가방·바람개비·책갈피·지도·풍경과 Art Kit 소품으로 대체 가능한 결과는 재생성하지 않는다. 부족한 결과 소품만 별도 투명 PNG로 발주한다. 아래 문장을 후속 GPT 요청에 붙인다.

```text
첨부한 승인된 사건 대본과 기존 소품 목록을 비교해, 기존 그림으로 표현할 수 없는 선택 결과만 새 게임 Sprite로 제작하세요. 각 결과는 선택 직후와 다음 방문의 숲에 같은 물건으로 보일 수 있어야 합니다. 항목별 파일명, 선택 ID, 즉시 표시 위치, 다음 방문 표시 위치를 먼저 표로 제시하고, 승인된 항목만 각각 투명 PNG로 그리세요. 분홍 바람 정령과 기존 숲 그림책 화풍을 유지하며 이야기·UI 텍스트를 이미지에 새기지 마세요.
```

**P3 월별 당시 초상:** 새 완성 그림을 월마다 생성할 필요는 없다. 당시 정령 포즈·성장 단계·장착 소품·사건 소품을 저장해 기존 앨범 프레임 안에 조합하는 구현이 우선이다. 조합으로 성장 차이를 보여줄 수 없을 때만 단계별 정령 오버레이를 발주한다.

**P4 성체·다음 정령:** 첫날 이름/성체 이름, 성장 기간, 독립과 다음 정령의 방식이 [기획서 §9](ForestDailyExperiencePlanV4.md#9-결정-필요-항목)에서 미결정이다. 성체 디자인과 다음 정령 세트의 장수·외형을 지금 확정 발주하지 않는다.

## 5. 아트 납품 확인 기준

- 원본 참고와 같은 분홍 정령으로 보이고, 읽기·이동·만들기에서 얼굴·몸 비율이 변하지 않는다.
- 각 PNG에 실제 알파 채널이 있으며 네 모서리와 오브젝트 사이가 완전 투명하다. 그려진 체커보드, 배경 번짐, 잘린 테두리가 없다.
- 2프레임 쌍은 같은 캔버스·중심·몸 크기여서 교차 표시 시 정령이 순간적으로 커지거나 튀지 않는다.
- 가구와 정령을 별도 Sprite로 놓았을 때 숲 배경의 캐릭터 중심과 UI 글 영역을 가리지 않는다.
- Unity 임포트 후 360×640, 1080×2340, 1366×768에서 윤곽·가독성과 Atlas 패킹을 확인한다. 이 검증이 끝나기 전에는 실제 사용 가능 리소스로 판정하지 않는다.
