# 기본 프로토타입 시각 기준

현재 구현 기준과 이후 보완할 아트를 구분한다. 최종 상용 아트 확정 문서가 아니다.

## 방향

작은 정령이 머무는 따뜻한 집과 앞마당. 실내는 크림색 벽·나무 바닥, 실외는 연한 잔디·둥근 수풀·디딤돌로 구분한다. 원본 GDD의 고정 공간·모듈 소품·재사용 애니메이션 원칙에 따라 현재 프로젝트의 Unity UI 기반 아트를 확장한다.

## 정령

- 정면: 둥근 연두색 몸체, 작은 얼굴, 머리의 잎. 표정보다 몸체·잎 실루엣이 먼저 읽힌다.
- 기본 비율: 프리팹 VisualRoot 205×230 기준. 몸체는 내부 폭 68%, 높이 65%를 차지한다. 성장에 따라 기존 크기 배율과 잎 수를 적용한다.
- 측면/후면: 이동 방향에 따라 얼굴의 가로 비율·위치를 바꾸거나 얼굴을 숨겨 옆/뒤를 표현한다. 몸체는 같은 도형을 재사용한다. 별도로 그린 캐릭터 시트는 아니다.
- 실제 렌더 참고: [방향 3종](Documentation/DirectionReference.png), [성체 3종](Documentation/AdultReference.png). 기본 정지 참고 시트는 프리팹의 기본 몸색을 사용하고 실제 생활 중에는 성장/행동 색이 적용된다.
- 준비 단계: 수첩/작은 가방/앞치마 천. 성체: 두루마리/모자·배낭/앞치마. 최종 진로와 준비 힌트를 구분한다.
- 표정: 기본·기쁨·궁금함·집중·졸림·놀람 6종을 눈·입·눈썹 메시로 표현한다. 원본 Face 참조는 보존하고 비표시한다. 눈 깜빡임, 도착 후 작은 기쁨 동작, 산책 중 발견 반응이 있다.

## 세계·소품

`CompanionWorldArt.LivingSpace.cs`가 집 벽·바닥·기둥·창문·수풀·꽃·디딤돌을 구성한다. `CompanionSoftShape`는 48개 외곽 점의 부드러운 도형 메시를 사용한다. 반복 도형에 랜덤 노이즈나 텍스처를 적용하지 않는다.

| 색 역할 | RGB 기준 | 사용처 |
|---|---|---|
| 짙은 나무 | 0.48, 0.36, 0.27 | 기둥·가구 다리·도구 |
| 밝은 나무 | 0.73, 0.57, 0.38 | 상판·창틀·침대틀 |
| 종이 크림 | 0.98, 0.94, 0.81 | 책·찻잔·꽃·디딤돌 |
| 모스 그린 | 0.39, 0.56, 0.37 | 수풀 음영·작은 도구 |
| 리프 그린 | 0.62, 0.74, 0.48 | 수풀·풀잎 |
| 피치 | 0.87, 0.65, 0.56 | 담요 |
| 스카이 | 0.73, 0.85, 0.85 | 창문 |

왼쪽 위가 밝고 아래쪽에 작은 접지 그림자가 오는 방향을 기본으로 한다. 두꺼운 외곽선 대신 색면으로 형태를 구분한다. 그림자는 어두운 초록의 약 16% 알파. 질감 강도는 0이며 모바일 축소 화면에서 읽히는 크고 단순한 형태를 우선한다.

현재 소품: 책·연필·나무 조각·망치·찻잔 2개·표지판·디딤돌·침대·베개·담요·창문·꽃·수풀. 별도 구매 장식인 책꽂이·공구함·꽃 찻잔·화분·쿠션은 장착 앵커를 통해 유지한다.

## UI

기존 WireframePalette의 크림 배경·짙은 녹색 글자와 버튼 위치를 유지한다. 새 세계 아트는 정령 공간 안에만 추가하며 버튼/기록 영역으로 확장하지 않는다. 새 도형은 raycastTarget=false. 장소 이름과 개발자 라벨은 원본 참조를 보존한다.

현재 본문 26~30, 메뉴 제목 44, 선택 버튼 29(Unity Canvas 기준). 실제 402×872 Game View에서 줄바꿈·글자와 정령의 겹침을 확인한다. 다른 종횡비와 실제 기기는 별도 확인이 필요하다.

## 검증·남은 일

- 집/앞마당 1곳과 가구 5곳: 실제 Play에서 표시 확인.
- 기존 직렬화 참조 유효, 새 도형의 레이캐스트 0개 확인.
- 다섯 행동마다 손에 든 책·망치/나무 조각·나뭇잎·찻잔·담요를 전환한다. 읽기는 기울임, 제작은 두드리기, 교류는 잔 들기, 산책은 발걸음·둘러보기, 휴식은 졸린 표정과 기존 낮은 호흡 움직임으로 구분한다.
- Play에서 읽기·교류·휴식 화면, 5종 소품/표정 전환, 소품 좌표 변화, 옆/뒤 얼굴 표시, 놀람·발걸음 값을 검증했다. 실제 기기의 가독성·모든 움직임 중단/복귀 조합, 진행 활동 전용 소품은 후속 검증/작업으로 남는다.
- 이 문서는 아트 제작의 현재 기준이다. 전체 GDD 완료를 뜻하지 않는다.
